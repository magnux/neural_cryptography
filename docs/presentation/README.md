## Updating the talk

Edit the PPTX in place and submit it under the same filename; Git records the
revisions. Native slide text, diagrams, the chart and tables can be edited. The
camera and matrix illustrations are embedded images. Change the speaker notes
along with the slide they explain. If slides move, update the agenda ranges
and this map.

For review, list the slides changed and briefly describe what changed; GitHub
doesn't show a useful line-by-line diff for a PPTX. Before submitting, open
the deck in slideshow and notes views and check any affected diagrams, links
and numbers against their sources. The repository copy is self-contained;
editing it does not update the original collaborative presentation or its
review threads.
