# Neural authentication demo

Read the root AGENTS.md, README.md and docs/NEURAL_AUTH_DEMO.md first.
This is a separate static app; preserve the Optical Bench as an independent
experiment. Do not deploy or reactivate either parked hosted site.

Edit this app's UI and simulation sources in dist/ outside dist/js/. The entire
dist/js/ tree is generated by scripts/prepare-apps.mjs from the canonical bench
and shared/browser-crypto sources. Change those sources and prepare again.
Keep worker, model and runtime URLs within this app's dist/ directory.

Live authentication must use trained W-tube/VW inference, RS+CRC recovery and
the shared authentication state machine. A simulation-only ideal output may
use target symbols only under its explicit user-visible assumption; it must
never be reachable by the live camera path. Keep its untrained models in
models/simulation-corrector/, separate from models/neural-corrector/.

Statistics have an explicit toggle. Do not retain timing samples or build detailed reports
when disabled. Keep capture and worker queues bounded, release streams/workers
on stop, and keep heavy cryptography/inference off the page thread.

Run npm run test:demo from the root after preparation. For canonical changes,
also run the affected bench/shared tests. Physical device behavior still needs
the manual checks in docs/NEURAL_AUTH_DEMO.md.
